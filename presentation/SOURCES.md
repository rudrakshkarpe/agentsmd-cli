## Presentation structure

- [Inside an Inference Request](https://rudrakshkarpe.com/presentations/inside-an-inference-request)
  informed the persistent phase rail, wireframe system anatomy, active payload,
  and speaker-controlled causal reveals.
- [`shivaylamba/animated-technical-illustrations`](https://github.com/shivaylamba/animated-technical-illustrations)
  supplied the semantic motion and verification method. Its repository credits
  Inside an Inference Request as the original storytelling inspiration.

- [`abhishekpanditofficial/agentcon-japan`](https://github.com/abhishekpanditofficial/agentcon-japan)
  informed the Poppins and IBM Plex typography, restrained presenter chrome,
  progress rail, staggered fragment pacing, dark and light themes, overview,
  notes, keyboard help, hash navigation, and architecture-first sequence.
- [`rohitg00/agentmemory/website`](https://github.com/rohitg00/agentmemory/tree/main/website)
  informed the replayable terminal behavior. The terminal scripts use this
  project's commands and checked-in evidence rather than AgentMemory copy.
- [`get-vix/vix`](https://github.com/get-vix/vix) informed the visual treatment
  of a declarative, multi-phase agent workflow. The agentsmd diagram does not
  claim Vix's branching or orchestration features; it renders this project's
  capture, reflection, evaluation, and rule-promotion lifecycle.
